# customize-site

You are working in a site generated by `video-to-site`. The scroll-driven canvas
engine in `src/app/page.tsx` is proven — treat it as load-bearing and edit
around it, not through it.

## Anatomy

- `src/app/page.tsx` — everything: canvas bootstrapping (`drawFrame`,
  `handleResize`, preload queue, rAF lerp loop), then plain React sections.
  Content lives in top-level data arrays (`PROJECTS`, `SKILLS`, `EXPERIENCE`,
  `SOCIALS`); sections map over them.
- `src/app/layout.tsx` — fonts + `<title>`/metadata. Change the tab title here.
- `src/app/globals.css` — reveal system (`.reveal` + IntersectionObserver),
  buttons, cards, timeline, scrollbar. Mobile safety nets live here
  (`overflow-x: hidden`, `word-break` policy, grid min-widths).
- `public/frames/frame-*.jpg` — the animation. Never rename; `getFrameSrc`
  expects zero-padded 4-digit names.

## Rules

1. **Don't touch the canvas engine** unless the request is about the animation
   itself (speed, quality, easing). Content requests stay in JSX + CSS.
2. **New sections** follow the existing pattern: `<section className="relative
   z-10">` + inner `max-w-6xl` container + `reveal` classes for scroll-in.
   The canvas is `position: fixed` behind everything — sections need no
   background unless the design calls for a solid panel (e.g. contact footer).
3. **Mobile first, always**: the audience is often on phones. Test widths at
   375px — clamp() font sizes, single-column grids, no fixed pixel widths that
   exceed the viewport. The `whitespace-nowrap` + oversized type combo is the
   classic overflow trap here.
4. **Frames are heavy** (~80MB/300 frames). Never commit build output (`.next/`),
   never re-encode frames with 4:2:0 chroma (it reintroduces block artifacts).
5. After edits: `<pm> run build` must pass before calling it done.

## Common tasks

- **Real content**: replace placeholder arrays + hero copy + `mailto:` links.
- **Demo media on cards**: put `public/demos/*.mp4` + poster JPGs, render
  `<video autoPlay muted loop playsInline preload="metadata" poster={...}>`.
  MP4 beats GIF (30fps, sharper, smaller).
- **Deploy**: push to GitHub, import into Vercel. Gotchas seen in the wild —
  `bun.lock` must point at `registry.npmjs.org` (not a mirror), configs as
  `.js` (CommonJS), `autoprefixer` installed.
